# Status Groupp

Новый сайт компании Status Groupp — каталог азиатских пивных брендов для
магазинов, ресторанов и дистрибьюторов.

Публичная версия: https://n1kseeman.github.io/status-groupp/

## Возможности

- главная страница в современном editorial-стиле;
- каталог с фильтрацией по брендам;
- страницы Tsingtao, Harbin, Singha и Saigon;
- разделы для партнёров, контакты и политика обработки данных;
- форма запроса прайс-листа через email или WhatsApp;
- подтверждение возраста 18+;
- адаптивная вёрстка для компьютеров и мобильных устройств.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
pnpm install
pnpm dev
```

## Проверка

```bash
pnpm test
```

## GitHub Pages

Публикация выполняется автоматически workflow-файлом
`.github/workflows/deploy-pages.yml`. Сборка создаёт статические страницы с
базовым путём `/status-groupp`.
